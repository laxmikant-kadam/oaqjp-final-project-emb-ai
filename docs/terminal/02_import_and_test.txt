NOTE ON THIS ENVIRONMENT
------------------------
The watson_nlp Emotion Predict endpoint used in the IBM Skills Network lab
(sn-watson-emotion.labs.skills.network) is only routable from inside the lab
network. On a normal machine the request raises ConnectTimeout, and
emotion_detection.py then uses the built-in offline model that returns the same
Watson JSON shape. Inside the lab the very same call goes to the real service.
See "Note on the Watson NLP endpoint" in README.md.
