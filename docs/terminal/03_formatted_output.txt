Terminal output showing that the output format is accurate
==========================================================

The modified emotion_detector() always returns a dictionary with the five
Watson emotion scores plus dominant_emotion, in this key order:

    anger, disgust, fear, joy, sadness, dominant_emotion

Script used (run from the project root)
---------------------------------------
from EmotionDetection.emotion_detection import emotion_detector

statements = [
    "I am glad this happened",
    "I am really mad about this",
    "I feel disgusted just hearing about this",
    "I am so sad about this",
    "I am really afraid that this will happen",
]

for statement in statements:
    result = emotion_detector(statement)
    print(f"Statement        : {statement}")
    print(f"  anger          : {result['anger']}")
    print(f"  disgust        : {result['disgust']}")
    print(f"  fear           : {result['fear']}")
    print(f"  joy            : {result['joy']}")
    print(f"  sadness        : {result['sadness']}")
    print(f"  dominant_emotion: {result['dominant_emotion']}")
    print()
